## ⚽ Quantify Sports

### Motor quantitativo para análise probabilística de partidas de futebol.

Projeto focado em **estatística, modelagem probabilística e análise de valor esperado**, criado para transformar dados esportivos em decisões quantitativas estruturadas.

O sistema possui uma arquitetura baseada em pipelines independentes responsáveis por modelagem, simulação, probabilidade, valor, risco e decisão.

**Alguns conceitos utilizados:**

- Distribuição de Poisson
- Dixon-Coles
- Simulações Monte Carlo
- Probabilidade implícita
- Expected Value — EV
- Kelly Criterion
- Modelagem de risco
- Confidence Score
- Análise estatística
- Arquitetura modular baseada em pipelines

```text
Context
   ↓
Model
   ↓
Simulation
   ↓
Probability
   ↓
Value
   ↓
Risk
   ↓
Ranking
   ↓
Decision
